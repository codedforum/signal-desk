    Tokenised real world assets

    /v5/real-world-assets/*

    Equities, commodities and funds that exist on chain, read from the v5 real world assets family. An asset here carries the registrant behind it, and every token traces back to the issuer that minted it.

    AssetTypeTokenised priceTokenised cap24h volume

    The same asset is tokenised by issuers who never agree a price with each other. This ranks the universe by how far apart those versions are, weighted by where the trading actually happens: a wide gap between two venues nobody uses is a small fact, and the weighted column is what says so. Every figure comes from one batched quote, so the whole board costs two API calls however many people read it.
